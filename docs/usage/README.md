# Usage guide

This guide takes you from a bare Linux machine to your first contained CodeCheck
review.

> **Status: pre-release.** codecheck-sandbox has not shipped a working release
> yet. Pages marked **Planned** describe the intended behaviour from the
> [design spec](../specs/2026-11-19-codecheck-sandbox-wizard.md); they turn into
> instructions as each part lands.

1. [Requirements](requirements.md): what your machine and account need.
2. [Install](install.md): getting the `codecheck-sandbox` binary.
3. [Setup](setup.md): the guided wizard, phase by phase.
4. [Commands](commands.md): every command and flag, including reviews.
5. [Troubleshooting](troubleshooting.md): what to do when a step fails.
6. [Privacy and telemetry](privacy-and-telemetry.md): what leaves your machine.
7. [Uninstall](uninstall.md): removing everything setup installed.

New to the design? Read the [architecture overview](../architecture.md) first.
